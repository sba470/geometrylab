# Проект для вычисления геометрических величин. 
## Описание функций.

## circle.area(r)
### Эта функция вычисляет площадь круга.
Ввод: 
- r — радиус круга.

Вывод: 
- площадь круга.

Пример:
```
print(circle.area(7))
```
## circle.perimeter(r)
### Эта функция вычисляет длину круга.
Ввод:
- r — радиус круга.

Вывод:
- длина круга.

Пример:
```
print(circle.perimeter(7))
```
## square.area(a)
### Эта функция вычисляет площадь квадрата.
Ввод:
- a — радиус круга.

Вывод: 
- площадь квадрата.

Пример:
```
print(square.area(7))
```
## square.perimeter(a)
### Эта функция вычисляет периметр квадрата.
Ввод:
- a — радиус круга.

Вывод: 
- периметр квадрата.

Пример:
```
print(square.perimeter(7))
```
## rectangle.area(a, b)
### Эта функция вычисляет площадь прямоугольника.
Ввод: 
- a — длина одной стороны прямоугольника.
- b — длина другой стороны прямоугольника.

Вывод:
- площадь прямоугольника.

Пример:
```
print(rectangle.area(7, 11))
```
## rectangle.perimeter(a, b)
### Эта функция вычисляет периметр прямоугольника.
Ввод: 
- a — длина одной стороны прямоугольника.
- b — длина другой стороны прямоугольника.

Вывод: 
- периметр прямоугольника.

Пример:
```
print(rectangle.perimeter(7, 11))
```
## triangle.area(a, h)
### Эта функция вычисляет площадь треугольника.
Ввод: 
- a — длина основания треугольника.
- h — высота, проведённая к основанию треугольника.

Вывод: 
- площадь треугольника.

Пример:
```
print(triangle.area(7, 11))
```
## triangle.perimeter(a, b, c)
### Эта функция вычисляет периметр треугольника.
Ввод: 
- a — длина первой стороны треугольника.
- b — длина второй стороны треугольника.
- c — длина третьей стороны треугольника.

Вывод: 
- периметр треугольника.

Пример:
```
print(triangle.perimeter(7, 11, 17))
```
