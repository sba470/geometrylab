# Проект для вычисления 
## Описание функций

## circus.area(r)
Эта функция вычисляет площадь круга.
- Ввод: r (int) — радиус круга.
- Вывод: float — площадь круга.
Пример:
```
print(area(7))
```
## circus.perimeter(r)
Эта функция вычисляет периметр круга.
- Ввод: r (int) — радиус круга.
- Вывод: float — длину круга.
Пример:
```
print(perimeter(7))
```
## square.area(a)
Эта функция вычисляет площадь квадрата.
- Ввод: a (int) — радиус круга.
- Вывод: int — площадь квадрата.
Пример:
```
print(area(7))
```
## square.perimeter(a)
Эта функция вычисляет периметр круга.
- Ввод: a (int) — радиус круга.
- Вывод: int — периметр квадрата.
Пример:
```
print(perimeter(7))
```
## rectagle.area(a, b)
Эта функция вычисляет площадь прямоугольника.
- Ввод: a (int) — длина одной из сторон прямоугольника; b (int) — длина другой стороны прямоугольника.
- Вывод: int — площадь прямоугольника.
Пример:
```
print(area(7, 11))
```
## rectagle.perimeter(a, b)
Эта функция вычисляет периметр прямоугольника.
- Ввод: a (int) — длина одной из сторон прямоугольника; b (int) — длина другой сторны прямоугольника.
- Вывод: int — периметр прямоугольника.
Пример:
```
print(perimeter(7, 11))
```
## triangle.area(a, h)
Эта функция вычисляет площадь круга
- Ввод: a (int) — длина длина треугольника, h (int) — высота, проведённая к основанию треугольника.
- Вывод: int — площадь треугольника.
Пример:
```
print(area(7, 11))
```
## triangle.area(a, b, c)
Эта функция вычисляет площадь круга
- Ввод: a (int) — длина первой стороны треугольника; b (int) — длина второй стороны треугольника; c (int) — длина третьей стороны треугольника.
- Вывод: int — периметр треугольника.
Пример:
```
print(perimeter(7, 11, 17))
```
